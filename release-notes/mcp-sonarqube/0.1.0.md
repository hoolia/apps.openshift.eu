# mcp-sonarqube 0.1.0

Released 2026-10-26.

## Changes

### First release

SonarQube as an MCP server (SonarSource sonarqube-mcp-server
1.30.0.4763) for a tenant or one of its teams, read-only by default. The
server holds no account: every request runs as the SonarQube user whose
token it carries. With credentials.mode perCaller each caller brings its
own user token; with credentials.mode broker a token broker gives every
agent its own SonarQube user, created on first use from the agent's
verified token, so no token is handed out by hand.
