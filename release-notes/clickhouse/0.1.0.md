# clickhouse 0.1.0

Released 2026-11-10.

## Changes

### First release

One ClickHouse 26.8 LTS server per release with a data volume and three users: an admin,
a read-only reader and a writer for ingestion tools, each with a generated password in
its own Secret. The official mcp-clickhouse 0.7.0 runs next to it as the reader and gives
AI agents read-only SQL tools through an MCP gateway.
