# activepieces 0.1.0

Released 2026-11-21.

## Changes

### Add the activepieces chart

Activepieces community edition 0.93.0, API and worker in one pod on port 8080 under
restricted-v2, with a PostgreSQL 17 database of CloudNativePG, a Valkey 8.1 job queue,
an optional barman-cloud backup and secrets from an existing Secret, a generated Secret
or a secret store. Code steps run in the V8 sandbox by default.
