# codex-worker 0.2.0

Released 2026-11-23.

## Changes

### Set the reasoning effort of the review model

`gateway.reasoningEffort` sets the reasoning effort of the model in `gateway.model`:
`low`, `medium`, `high`, `xhigh` or `max`. The worker writes it into the CLI
configuration of each review. Empty, the default, keeps the effort the CLI picks for the
model, as in 0.1.0.

Any other value fails the chart schema, and the image stops a review with such a value
before it reads a credential or starts the model.

## Upgrade

Build or pull worker image 0.2.0 and set `image.tag` to it: an image of 0.1.0 ignores the
new setting. Stop submissions and drain queued reviews before the upgrade; the pod is
recreated. No value of 0.1.0 changes its meaning.
