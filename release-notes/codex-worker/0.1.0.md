# codex-worker 0.1.0

Released 2026-11-21.

## Changes

### Run serialized Codex reviews through a private HTTPS worker

Install one worker with retained block storage, separate request and auth-store
credentials, restricted security settings and optional tenant monitoring.

The Codex CLI runs in a container of its own that holds no credential and shares only
an exchange directory with the worker.

Supply a real worker image repository and version tag, both GitLab project IDs, the API
URL, credential Secrets and caller-selected storage/network settings. This chart
intentionally requires deployment values; its CI fixture is not deployable.
Image publication and authentication bootstrap are separate operator steps.

## Upgrade

This is the first chart version. Stop submissions and drain queued reviews before
later upgrades, credential rotation or removal. State claims survive chart removal;
reuse the retained claim explicitly when reinstalling.
