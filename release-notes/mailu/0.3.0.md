# mailu 0.3.0

Released 2026-11-15.

## Changes

### An empty mail domain switches mail off

With `upstream.domain` empty the chart renders no object: no mail server, no Secret, no
Route, no DNS records and no DKIM key. An installation that cannot pass a boolean, such as
a form that leaves the mail domain empty, installs without mail this way.

Before, an empty domain failed the install with "You need to set the domain to be used".

Emptying the domain of a running mail server deletes the mail server and its mail volume.

### Upstream chart in this repository

The upstream chart `mailu` 2.6.3 is kept in this repository (`vendor/mailu`) instead of
being downloaded from the Mailu chart repository. Its values stay below `upstream:`. With a
mail domain it renders the same objects as before.
