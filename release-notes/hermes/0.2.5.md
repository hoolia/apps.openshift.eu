# hermes 0.2.5

Released 2026-11-08.

## Changes

### A2A without a stored token

The A2A token Secret of 0.2.4 is gone. The gateway's A2A server stays on loopback; the new
sidecar `a2a-auth` on Service `<release>-a2a` (port 8090) admits a bearer JWT of the
tenant: a ServiceAccount token from a namespace `<tenant>` or `<tenant>-*`, or an OIDC
token whose groups claim holds the tenant. The kagent relay forwards its caller's token.

## Upgrade

`secrets.a2aToken`, `secrets.externalSecret.items.a2aToken` and `a2a.peer` are removed;
`a2a.port` is the sidecar's port (8090), `a2a.gatewayPort` the gateway's (9900). With
`a2a.enabled` off nothing changes.
