# hermes 0.2.8

Released 2026-11-08.

## Changes

### file-server readiness

The readiness probe of container `file-server` checks the loopback port from inside the
container. The TCP probe of 0.2.7 dialed the pod IP, where the server does not listen, so
a pod with `fileServer.enabled` never became Ready.
