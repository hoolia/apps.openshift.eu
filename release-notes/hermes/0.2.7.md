# hermes 0.2.7

Released 2026-11-08.

## Changes

### Files of a volume at a path of the dashboard host

`fileServer.enabled` serves one extraVolume (`fileServer.volume`) read-only at
`https://<route.host>/downloads/` (`fileServer.path`), with a directory listing. A new
container `file-server` listens on loopback port 8899 only; oauth-proxy forwards that path
to it, so the dashboard login protects the files.

## Upgrade

No value changes. Off by default; to serve a shared download directory:

```yaml
fileServer:
  enabled: true
  volume: downloads
```
