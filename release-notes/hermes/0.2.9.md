# hermes 0.2.9

Released 2026-11-08.

## Changes

### The agent knows its public URL and how to hand over files

Containers `gateway` and `dashboard` get `HERMES_ENVIRONMENT_HINT`, text that Hermes adds
to the system prompt. It tells the agent to hand over a file with a `MEDIA:<absolute path>`
line, which the dashboard chat shows as a download. With `route.host` it adds the URL the
user opens; with `fileServer.enabled` it adds the `https://<route.host>/downloads/` link for
files of that volume. `environmentHint` appends own text.

`dashboard.public_url` stays unset: a non-loopback value switches on the dashboard's own
login gate behind oauth-proxy.
