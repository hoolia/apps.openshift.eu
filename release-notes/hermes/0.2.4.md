# hermes 0.2.4

Released 2026-11-08.

## Changes

### A2A

New values `a2a.*`. With `a2a.enabled` the gateway serves A2A v1.0 on Service
`<release>-a2a` (port 9900) behind a bearer token from Secret `<release>-a2a`, and kagent
gets a BYO Agent named like the release that relays to it with the token.

### Gateway restarted from the dashboard

A gateway restarted from the dashboard runs in the dashboard container. The gateway
container no longer exits and restarts in a loop then; it waits and starts the gateway
again when that one stops.

## Upgrade

Defaults are unchanged: `a2a.enabled` is false. Under Argo CD pass `secrets.a2aToken`, or
the token changes on every render.
