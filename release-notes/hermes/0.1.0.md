# hermes 0.1.0

Released 2026-11-07.

## Changes

### First release

Hermes Agent 0.23.0 with its web dashboard on loopback behind the OpenShift login, a
token proxy to the model and MCP gateway, and `mcp-sync`, which keeps `mcp_servers` of
`config.yaml` in step with the kagent `RemoteMCPServers` the agent may list. MCP servers
that each user authorizes with OAuth get the dashboard behind the Route as their callback.
Skill repositories are cloned at every start.
