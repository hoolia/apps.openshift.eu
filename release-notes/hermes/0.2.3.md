# hermes 0.2.3

Released 2026-11-08.

## Changes

### Gateway name

New value `llm.providerName`. With a name, config.yaml gets a provider entry
`providers.<id>` (id: the name in lower case, other characters as `-`) with that name, the
token proxy address and the default model, and `model.provider` names it. `/model` and
`hermes status` then show the name instead of "Custom endpoint".

## Upgrade

Defaults are unchanged: without the value Hermes keeps `provider: custom`.
