# hermes 0.3.1

Released 2026-11-08.

## Changes

### Telegram channel as a value

New values `telegram.secretName` and `telegram.key` (default `telegram-bot-token`). With a
Secret name, containers `gateway` and `dashboard` get that Secret key as env
`TELEGRAM_BOT_TOKEN`, which switches the gateway's Telegram channel on. Both containers get
it because a gateway restarted from the dashboard runs in container `dashboard`; the
gateway lock keeps one instance polling the bot.

With `secrets.type: externalSecret`, `secrets.externalSecret.items.telegramBotToken` names
the vault item whose password is the token. The chart makes ExternalSecret
`<release>-telegram` and wires `telegram` to it; an explicit `telegram.secretName` wins.

`telegram.allowedUsers` (numeric Telegram user ids) becomes `TELEGRAM_ALLOWED_USERS`. Anyone
else who messages the bot gets a pairing code, approved with
`hermes pairing approve telegram <code>`.

## Upgrade

No value changes: without a token nothing is added and the pod does not restart.
