# hermes 0.2.1

Released 2026-11-08.

## Changes

### Single sign-on is on by default

`sso.enabled` defaults to `true`, and the Secret it reads defaults to `public-<release>`,
the Secret the platform makes for a StatefulSet with its label (`statefulSet.labels`).
While that Secret is not there, or `route.host` is empty, the dashboard runs without a
login of its own, as in 0.1.x. An install without the label behaves as before.

### Login switched on and off without a pod restart

The dashboard container mounts the Secret as an optional volume and its start script
`dashboard.py` reads the client every `sso.interval` seconds (default 30). When the client
appears, changes or goes, it restarts the dashboard process in the same container with the
new login or without one; the pod and its other containers keep running. The dashboard
is not ready for a few seconds during that restart. Before, the dashboard container waited
in `CreateContainerConfigError` until the Secret existed.

## Upgrade

Change `targetRevision` to 0.2.1. The pod restarts once. A release that set
`sso.secretName` keeps that Secret. To keep single sign-on off where the platform labels
the StatefulSet, set `sso.enabled: false`.
