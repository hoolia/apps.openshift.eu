# hermes 0.5.1

Released 2026-11-21.

## Changes

### MCP tool call timeout

The MCP servers that `mcp-sync` writes into the Hermes configuration get a timeout of
300 seconds instead of 120: one tool call may run as long as the platform gateway and the
other MCP clients allow.

## Upgrade

Nothing to do. The next `mcp-sync` run rewrites the entries.
