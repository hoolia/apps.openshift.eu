# hermes 0.2.2

Released 2026-11-08.

## Changes

### Volumes shared with other pods

New value `podSecurityContext.fsGroup`: the group of the pod's volumes, default
`image.uid`. With the default, kubelet re-owns a shared `extraVolume` (a browser's
downloads) to that group at every start, and a pod of the project that runs under
`restricted-v2` can no longer write to it. Set the first group of the project's range
(namespace annotation `openshift.io/sa.scc.supplemental-groups`): kubelet adds the fsGroup
to every container's groups, so Hermes keeps its home and the other pod can write.

## Upgrade

Defaults are unchanged.
