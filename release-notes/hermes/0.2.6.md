# hermes 0.2.6

Released 2026-11-08.

## Changes

### A2A v0.3 callers

kagent calls a BYO agent with `A2A-Version: 0.3`, which the gateway refuses: it speaks
v1.0 only. The `a2a-auth` sidecar now drops that header for a v0.3 caller and returns the
gateway's answers, plain and streamed, in v0.3 shape: lower-case states, roles `agent` and
`user`, `kind` on tasks, messages, parts and events, and `final` on a terminal status
update. v1.0 callers are unchanged.

No value changes.
