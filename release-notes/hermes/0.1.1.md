# hermes 0.1.1

Released 2026-11-08.

## Changes

### Login keeps working after the first hour

The ServiceAccount token of `oauth-proxy` and `mcp-sync` is requested with
`expirationSeconds: 3607`, as in the default token mount. `oauth-proxy` reads the token
once at start as its OAuth client secret; a token that expired after one hour made every
login after that fail with `unauthorized_client` and an error page 500.

## Upgrade

Change `targetRevision` to 0.1.1. The pod restarts once.
