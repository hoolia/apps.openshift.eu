# hermes 0.2.0

Released 2026-11-08.

## Changes

### Chat works behind the Route

With `sso.enabled` the chart sets the dashboard's public address to
`https://<route.host>` and switches on the Hermes dashboard login `self-hosted`, an
OpenID Connect client read from the Secret `sso.secretName`. Hermes accepts the chat
WebSockets (`/api/ws`, `/api/events`, `/api/pub`) only from the browser origin of its
public address, and serves a public address only behind a login of its own. Without
it every chat socket behind a Route was closed with code 4403. `oauth-proxy` stays in
front as the group check.

### Labels on the StatefulSet

`statefulSet.labels` puts extra labels on the StatefulSet only, not on its pods, so a
platform policy can create the OpenID Connect client and its Secret from a label.

## Upgrade

Change `targetRevision` to 0.2.0 and add `sso.enabled: true`, `sso.secretName` and,
for a client the platform creates, the label it needs in `statefulSet.labels`. The
client needs the redirect URI `https://<route.host>/auth/callback`. Without `sso` the
upgrade changes nothing. With it the pod restarts once and its dashboard container
waits until the Secret exists.
