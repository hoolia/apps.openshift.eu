# hermes 0.4.0

Released 2026-11-19.

## Changes

### Public MCP servers are opt-in checkboxes

A `RemoteMCPServer` of a public server of the platform (`mcp.catalog`: `playwright`, `firecrawl`) is no longer used just because the agent may list it. The agent uses one only when its name is ticked in `mcp.options`. Nothing ticked means no public servers. A name in `mcp.options` that is not in `mcp.catalog` fails the render.

## Upgrade

Before moving to this version, tick the servers the agent has today: `mcp.options: [playwright, firecrawl]`. Without that, the agent loses `public-playwright` and `public-firecrawl` at the next `mcp-sync` pass.
