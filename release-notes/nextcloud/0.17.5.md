# nextcloud 0.17.5

Released 2026-11-10.

## Changes

### Calendar and Contacts installed by default

`settings.apps` defaults to `[groupfolders, calendar, contacts]`. Every Nextcloud installs
and enables Calendar and Contacts at its next start, next to Team folders.

## Upgrade

The upgrade restarts Nextcloud. A release that sets `settings.apps` itself keeps its own
list: add `calendar` and `contacts` to it to get them. To leave them out, set
`settings.apps: [groupfolders]`; an app that is already installed stays installed.
