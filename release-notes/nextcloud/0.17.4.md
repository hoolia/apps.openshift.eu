# nextcloud 0.17.4

Released 2026-11-07.

## Changes

### Single sign-on is on by default

`sso.enabled` defaults to `true`. Nextcloud sets up its login provider from Secret
`public-nextcloud` when the platform makes one, and does nothing while the Secret is not
there. The platform answers only a Deployment with its label (`nextcloud.deploymentLabels`),
so an install without the label behaves as before. Local logins keep working.

### Single sign-on switched on without a restart

The background loop runs the provider setup whenever the chart mounts it, so switching
`sso.enabled` on for a running Nextcloud takes effect within a minute. Before, the loop of a
pod started without it never set the provider up until the pod was recreated.

## Upgrade

Nothing to do. To keep single sign-on off where the platform labels the Deployment, set
`sso.enabled: false`.
