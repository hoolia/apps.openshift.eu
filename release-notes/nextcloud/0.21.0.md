# nextcloud 0.21.0

Unreleased.

## Changes

### Talk servers of the platform

Two switches, both off by default, let Talk use servers that the platform runs instead of
its own:

- `talk.shared.signaling`: Nextcloud and the recording server use the signaling server at
  `signaling-url` of ConfigMap `nextcloud-talk-platform`. The chart then creates no
  signaling server, NATS, `/talk/signaling` Route, their ServiceMonitors or their alerts.
  The recording server, its volume and Secret `nextcloud-talk` stay.
- `talk.shared.turn`: Nextcloud registers every server in `turn-servers` of that ConfigMap
  as STUN and TURN server, with the key in Secret `nextcloud-talk-shared-turn`. The chart
  then creates no TURN server, Service or NetworkPolicy. `talk.shared.turnGeneration`
  must name the `turn-generation` of the ConfigMap; a change registers the new key.

`talk.shared.keepOwnServers` keeps the own servers, the `/talk/signaling` Route and the TURN
Service with its address running, unused, while an existing instance moves over; turning a
switch off again then needs nothing to start. Remove it once the new servers are proven.

The platform writes the ConfigMap and the Secret; the chart only reads them. While a value
is missing or invalid, Talk keeps its last servers, the `nextcloud` container logs
`setup: shared Talk:` with the reason, and the cron container tries again every minute.

### Recordings survive a restart of the recording server

The start script of the recording image empties `/tmp`, where the chart mounted the
recording volume. Every restart deleted the recordings in progress and those the server
keeps after a failed upload. The volume is now mounted at `/recordings`, and the recording
server writes there. If an image no longer writes `directory = /tmp` into its
configuration, the recording server stops instead of recording into the container.

## Upgrade

No action: both switches are off. The Nextcloud and Mailu front pods restart once for the
`chart-version` pod annotations, and the recording server once for its new mount.
