# nextcloud 0.19.0

Released 2026-11-15.

## Changes

### An empty mail domain switches mail off

With `mailu.upstream.domain` empty Nextcloud runs without mail, the same as with
`mailu.enabled=false`: no Mailu mail server, no mail Route on the Nextcloud host, no
webmail login and no Mail app setup. An installation that cannot pass a boolean, such as
a form that leaves the mail domain empty, installs without mail this way.

Emptying the domain of a running installation deletes its mail server and mail volume.

### Mailu 0.3.0

The bundled Mailu renders nothing without a mail domain; see the release notes of
mailu 0.3.0.

## Upgrade

Nothing to do. The pods of Nextcloud and of the Mailu front restart once: the annotation
`chart-version` of their pod template follows the chart version.
