# nextcloud 0.20.2

Released 2026-11-25.

## Changes

### Stable credentials of the office agent's token check

Bundles mcp-officeagent 0.3.2: `mcp-officeagent.auth.cookieSecret` accepts a value of any
length. Pass `mcp-officeagent.auth.cookieSecret` and `mcp-officeagent.auth.clientSecret`
when a GitOps tool renders the chart without cluster access, such as Argo CD; without them
the Secret `officeagent-auth` gets new values on every render.

## Upgrade

Nothing to do. Without the two values, the Secret is generated again at the upgrade, as
before; the token check uses neither value for bearer tokens, so callers are not affected.
