# nextcloud 0.14.0

Released 2026-10-27.

## Changes

### Every user finds a mailbox in the Mail app

With the mail server of the chart on (`mailu.enabled`, default) and `mail.enabled`
(default), the Mail app is installed and every Nextcloud user gets a mailbox
`<user id>@<mail domain>` on Mailu, connected in the Mail app with an app token of that
mailbox. It works for users who log in with OpenID Connect and have no Nextcloud
password. New users get theirs within a minute. The mail domain is
`mailu.upstream.domain`. A mailbox that exists already and was not made for that user
is left alone.

### Team folders at the first start

The setup script installs and enables the apps listed in `settings.apps` at every start.
The default is `groupfolders`, Team folders.

### The OnlyOffice app follows onlyoffice.enabled

With `onlyoffice.enabled=false` the setup script disables the app `onlyoffice` instead of
leaving it enabled without a document server.

### Mailu 0.2.1

The mail server moves to `mailu` 0.2.1 (release notes of `mailu` 0.2.1) and is packaged
with the chart instead of coming from the chart repository's index.

## Upgrade

Set `mailu.upstream.domain`, `mailu.upstream.initialAccount.domain` and
`mailu.upstream.hostnames` to your mail domain if you have not done so: the mailboxes
are made in `mailu.upstream.domain`. The Nextcloud pod restarts once. To keep the Mail
app out, set `mail.enabled=false`; to keep Team folders out, set `settings.apps: []`.
