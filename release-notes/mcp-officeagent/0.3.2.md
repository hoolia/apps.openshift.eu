# mcp-officeagent 0.3.2

Released 2026-11-25.

## Changes

### Cookie secret of any length

`auth.cookieSecret` accepts a value of any length. A value that is not 16, 24 or 32 bytes
long, which oauth2-proxy refuses, is replaced by the first 32 characters of its SHA-256
hash. A GitOps tool can now pass any generated secret, so the Secret no longer changes on
every render.

## Upgrade

Nothing to do. A value of 16, 24 or 32 bytes, or an empty one, works as before.
