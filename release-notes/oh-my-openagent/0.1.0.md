# oh-my-openagent 0.1.0

Released 2026-11-15.

## Changes

### First release

A personal OpenCode coding agent with oh-my-openagent (OmO) 5.1.70 loaded, built on chart
opencode-agent 0.9.0: browser UI behind the OpenShift login, A2A for other agents, a work
tree on a persistent volume. OmO's telemetry and auto update are off. OmO's configuration
`~/.omo/omo.jsonc` comes from the value `agent.opencode.homeFiles` and is rewritten on
every start.
