# oh-my-openagent 0.2.0

Released 2026-11-19.

## Changes

### Public MCP servers are opt-in checkboxes

New `mcp.options` and `mcp.catalog`: the ticked public servers are written into `~/.omo/agent/mcp.json` on every start, next to the servers the user added. Nothing ticked means no public servers. A name in `mcp.options` that is not in `mcp.catalog` fails the render.
