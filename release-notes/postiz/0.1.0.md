# postiz 0.1.0

Initial release - publication pending.

## Changes

### New chart: Postiz

Postiz 2.25.3 social media scheduler with its MCP server, run as three unprivileged
processes behind nginx, a PostgreSQL database, a Valkey store and a Temporal server with
its state on a volume. Developer app credentials of the channels come from a Secret or a
secret store.
