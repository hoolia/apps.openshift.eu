# mcp-onlyoffice 0.1.0

Released 2026-10-26.

## Changes

### New chart: the ONLYOFFICE Docs MCP server for a project's agents

Runs the official ONLYOFFICE docs-mcp server against your ONLYOFFICE Document Server.
Agents create blank Word, Excel, PowerPoint and PDF documents, open documents from the
origins you allow in `fileUrlAllowedOrigins`, edit them in the embedded ONLYOFFICE editor
and save the result. The server serves streamable HTTP at `/mcp` behind an MCP gateway and
admits only the own project and the namespaces you list.

### You provide the image and the Document Server's JWT secret

ONLYOFFICE publishes no server image: build it from the upstream repository and set
`image.repository` and `image.tag`. The JWT secret comes from `secrets.jwtSecret` or a
vault item (`secrets.type: externalSecret`).
