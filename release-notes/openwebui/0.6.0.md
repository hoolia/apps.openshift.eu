# openwebui 0.6.0

Released 2026-11-20.

## Changes

### Public MCP servers are always offered again

Every server of `mcp.catalog` (`playwright`, `firecrawl`) is offered again once the token proxy has a gateway, each as its own tool server at `/mcp/public/<server>` that the user can switch off. In 0.5.0, a server was offered only when it was ticked in `mcp.options`, and nothing ticked meant no public servers. `mcp.options` now has no effect, and a name outside `mcp.catalog` no longer fails the render. An entry of the same name in `mcp.endpoints` still wins.

### A Playwright MCP server of the team

`mcp-playwright.enabled: true` deploys the chart `mcp-playwright` as a dependency into the release namespace, as `<release>-playwright`, and offers it as the tool server `<release>-playwright` at `/mcp/<namespace>/<release>-playwright` through the token proxy. Every value of `mcp-playwright` applies under that key. `networkPolicy.ingressNamespaces` must admit the MCP gateway, or the gateway cannot reach the server. Off by default.

### Token proxy: separate MCP gateway

The token proxy reads two new variables. `MCP_UPSTREAM` sends requests under `/mcp` to that gateway instead of `UPSTREAM`, and `MCP_TOKEN_FILE`, required with it, names the projected token it sends there, so a token for `UPSTREAM` never reaches another host. Without them nothing changes.

## Upgrade

No values change. A new instance with a gateway gets the public tool servers. An existing instance keeps the tool servers in its database unless `persistentConfig` is false. Values that tick `mcp.options` keep rendering; the ticks can go.
