# openwebui 0.5.0

Released 2026-11-19.

## Changes

### Public MCP servers are opt-in checkboxes

The default `mcp.endpoints` no longer includes `public` (the combined `/mcp/public`, which the gateway removes). Public servers are ticked in `mcp.options`, one tool server each at `/mcp/public/<server>`. Nothing ticked means no public servers. A name in `mcp.options` that is not in `mcp.catalog` fails the render.

## Upgrade

An instance with `mcp.enabled` and empty `mcp.endpoints` loses its `public` tool server; tick `mcp.options` instead. Instances with their own `mcp.endpoints` are unchanged.
