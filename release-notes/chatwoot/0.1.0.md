# chatwoot 0.1.0

Initial release - publication pending.

## Changes

### New chart: Chatwoot Community Edition

Chatwoot 4.19.1 Community Edition with web and worker, a PostgreSQL database with
pgvector, a Valkey store and attachments on a volume or in a bucket. A Job migrates the
database and creates the account and its super admin on install, so no signup or
onboarding page opens. With `sso.enabled` staff log in at an OIDC provider through
oauth2-proxy and a login bridge, and only the widget's paths are reachable without a
login. A Chatwoot dashboard session lasts `sso.session.chatwootHours`, default 36, from
25 to 720 hours; the chart refuses other values.
