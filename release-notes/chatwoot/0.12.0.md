# chatwoot 0.12.0

Released 2026-11-21.

## Changes

### The bot's agent can make an Odoo quotation

With `agentBot.quotations.enabled`, an answer of the bot's agent with a line
`QUOTE {json}` never reaches the visitor. The bridge passes the JSON object to Odoo
(`sale.order` `grncloud_chat_quote` of module `grncloud_chat_order`), with the
conversation and, for a logged-in visitor only, the verified email. Odoo checks the request,
makes the quotation and mails it; the visitor gets `agentBot.quotations.sentMessage` or
`refusedMessage`, and the agent reads the outcome in the bridge note of the next message.
A failure of Odoo hands the conversation to a person.

## Upgrade

- Nothing changes until you set `agentBot.quotations.enabled`.
- It needs `odoo.website.identity.records` (the bridge's Odoo key), module
  `grncloud_chat_order` in Odoo, and the bridge's Odoo user in its group
  "Website chat quotations".
- Tell the agent the `QUOTE` line format before you enable it.
- The agent bridge restarts once.
