# chatwoot 0.10.1

## Changes

### The handoff marker counts anywhere in an answer

An answer of the agent hands the conversation to a person when it holds
`agentBot.handoff.marker` as a word of its own, also inside a sentence
("I'll pass you to a colleague. HANDOFF"). Before, only an answer that was exactly the marker
handed off, and the customer saw the rest of the text with the marker in it. The customer
now gets `agentBot.handoff.message` instead of such an answer.
