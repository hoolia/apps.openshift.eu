# chatwoot 0.13.1

Released 2026-11-22.

## Changes

### ConfigMap chatwoot-scripts applied server-side

Since 0.12.0, with every feature on, ConfigMap `chatwoot-scripts` is larger than the
262144 bytes that an object's annotations, the `last-applied-configuration` of a
client-side apply included, may hold, so an Argo CD sync without server-side apply failed on it. The ConfigMap now carries
`argocd.argoproj.io/sync-options: ServerSideApply=true`, and Argo CD applies it server-side
whatever the Application's own sync options are.

### A lead instead of a quotation

With `agentBot.quotations.enabled`, Odoo may answer a quotation request with a lead
(`"lead": true`) when people send the quotation themselves. The visitor then gets the new
value `agentBot.quotations.leadMessage` (`{email}`), or with it empty the `message` of
Odoo's answer, instead of `sentMessage`; the conversation stays with the bot. Real
quotations keep `sentMessage`.

## Upgrade

- The bridge script changed, so the scripts checksum changes and the pods that mount the
  scripts restart once. The annotation itself is not part of the checksum.
- `agentBot.quotations.enabled` stays off by default.
- An Application that turned on `ServerSideApply=true` only because of this ConfigMap can
  turn it off; nothing else requires it.
