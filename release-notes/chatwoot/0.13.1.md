# chatwoot 0.13.1

Released 2026-11-22.

## Changes

### ConfigMap chatwoot-scripts applied server-side

Since 0.12.0, ConfigMap `chatwoot-scripts` is larger than the 262144 bytes that the
`kubectl.kubernetes.io/last-applied-configuration` annotation of a client-side apply may
hold, so an Argo CD sync without server-side apply failed on it. The ConfigMap now carries
`argocd.argoproj.io/sync-options: ServerSideApply=true`, and Argo CD applies it server-side
whatever the Application's own sync options are.

## Upgrade

- No pod restarts: the annotation is not part of the scripts checksum.
- An Application that set `ServerSideApply=true` only for this ConfigMap can drop it.
