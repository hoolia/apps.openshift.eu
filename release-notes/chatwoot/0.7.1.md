# chatwoot 0.7.1

## Changes

### The prepare Job keeps the sales label

With `odoo.website.enabled` the prepare Job creates the label `odoo.website.salesLabel` in
the account when it is missing, so staff can pick it in a conversation. A label that
already exists keeps its colour and description. An empty `odoo.website.salesLabel`
creates none.

`odoo.website.salesLabel` must be a Chatwoot label name: lower case letters, digits, `-`
and `_`, at most 64 characters, or empty. The chart refuses any other value.

## Upgrade

No value changes for a label that matches the rule above. The prepare Job and every pod
that reads the scripts ConfigMap restart once.
