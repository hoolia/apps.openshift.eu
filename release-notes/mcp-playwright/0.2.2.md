# mcp-playwright 0.2.2

Released 2026-11-07.

## Changes

### Downloads on a shared volume

New values `outputDir`, `extraVolumes` and `extraVolumeMounts`. Point `outputDir` at a
mounted ReadWriteMany volume and an agent that mounts the same volume reads the files
the browser downloads.

## Upgrade

Defaults are unchanged: `outputDir` stays `/tmp/output`.
