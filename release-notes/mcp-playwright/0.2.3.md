# mcp-playwright 0.2.3

Released 2026-11-20.

## Changes

### Runs as a subchart

New `nameSuffix` (default empty) is appended to the release name for every object name, the pod labels and the default target name. An agent chart that includes this chart sets `-playwright`, so the server's Service and pods do not take the agent's own names and selectors. With the default the rendered objects are unchanged.
