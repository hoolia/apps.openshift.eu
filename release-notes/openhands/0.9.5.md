# openhands 0.9.5

Released 2026-10-25.

## Changes

### Attach files up to 10 GB in the browser

The browser accepted chat attachments up to 3 MB, per file and in total. The new
value `build.maxUploadMB` sets that limit, 10240 (10 GB) by default; 0 removes it.
The agent server writes uploads to disk as they arrive, so a large file needs room
on the workspace volume. Images that are embedded in the message instead of uploaded
as a file still go to the model, which rejects large ones. The image is rebuilt on
upgrade.
