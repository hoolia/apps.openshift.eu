# openhands 0.19.1

Released 2026-11-08.

## Changes

### Google login lets you choose the account

An MCP server that logs in at Google (`accounts.google.com`) now asks with
`prompt=select_account consent` instead of `prompt=consent`. Google shows its account
chooser, so a user whose browser is signed in to another Google account picks the right one.
Google still returns a refresh token, so the login keeps working after an hour.

## Upgrade

Nothing to do. The agent image is rebuilt once and the agent pod restarts, because the chart
version is part of the image tag.
