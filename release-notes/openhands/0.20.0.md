# openhands 0.20.0

Released 2026-11-09.

## Changes

### LLM settings for one model

The new value `llm.modelProfileDefaults` holds settings for the profiles of one model only,
keyed by the model name after the last `/`. It is laid over `llm.profileDefaults` with the
same rule: written into new profiles, and into existing ones once per value, so an edit in
**Settings > LLM** stays until the value changes.

Use it for a model that needs other settings than the rest. For example, the chat template
of GLM 5.3 Flash thinks at its longest unless `reasoning_effort` is `low` or `high`, and at
`high` some agent turns still spend 5,000 to 10,000 tokens thinking:

```yaml
llm:
  modelProfileDefaults:
    glm-5.3-flash:
      reasoning_effort: low
```

Conversations that already exist keep the settings they started with.

## Upgrade

Nothing to do: the default is empty and leaves every profile as it is. The agent image is
rebuilt once and the agent pod restarts, because the chart version is part of the image tag.
