# openhands 0.22.0

Released 2026-11-11.

## Changes

### The editor chat asks the gateway for its models once an hour

`vscode-sync` asked the gateway for its model list on every pass, once a minute for every
agent, and a gateway may ask every provider behind it for each such request. It now uses one
answer for `vscode.chat.modelsInterval` seconds, 3600 by default. A model the gateway adds or
drops shows in the editor chat within that time, or after a restart of the pod, instead of
within a minute. The MCP servers of the chat are still kept in step on every pass.

When the gateway does not answer, the chat keeps the models of its last answer. Before, a
release with `vscode.chat.models` set lost every other gateway model from the chat until the
gateway answered again.

## Upgrade

Nothing to do. `vscode.chat.modelsInterval: 0` reads the list on every pass, as before. The
agent image is rebuilt once under the tag `1.38.0-0.22.0` and the agent pod restarts.
