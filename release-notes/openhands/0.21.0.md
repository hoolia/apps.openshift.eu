# openhands 0.21.0

Released 2026-11-10.

## Changes

### Agent Canvas 1.38.0

The image is OpenHands Agent Canvas 1.38.0 with agent-server 1.61.0, pinned by digest.
Among the upstream changes: new conversations start at once and show their startup in the
chat, the agent status is shown live, the Paper theme, conversation budgets, and Codex over
ACP 2.2.2. A new conversation without a picked repository works in
`~/.openhands/agent-canvas/workspaces/<conversation>` on the volume.

### The editor is code-server

The **VS Code** tab now runs Coder code-server instead of OpenVSCode Server. The extensions
of `vscode.extensions` (Continue by default) are built into the image as code-server
built-in extensions, and `vscode.settings` goes into the machine settings of code-server,
`~/.local/share/openhands-code-server/8001/Machine/settings.json`.

## Upgrade

The agent image is rebuilt once and the agent pod restarts. Editor settings and extensions
a user installed in OpenVSCode Server stay behind in `~/.openvscode-server` and are not
taken over by code-server: install such an extension again from the editor.
