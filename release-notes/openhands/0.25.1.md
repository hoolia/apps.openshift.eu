# openhands 0.25.1

Released 2026-11-20.

## Changes

### A custom image repository is pulled by its tag

The default `image.digest` is the digest of `ghcr.io/openhands/agent-canvas`. An instance that set its own `image.repository` got that digest attached to its own repository, which has no such manifest, so the pod could not pull its image. The digest now applies only to `ghcr.io/openhands/agent-canvas`; another repository is pulled by `image.tag`.

## Upgrade

Nothing to do. An instance on the default repository renders the same image.
