# openhands 0.21.1

Released 2026-11-10.

## Changes

### The image build installs every npm tool again

The npm of Agent Canvas 1.38.0 skips the install scripts of a package unless they are
allowed, so the build of 0.21.0 failed: `@higgsfield/cli` downloads its program in its
install script. Each npm tool of `build.tools` may now run its own install scripts; a
dependency's scripts run only when the tool's `args` name it with
`--allow-scripts=<package>`. `@mermaid-js/mermaid-cli` allows `puppeteer`.

The build check of `@mermaid-js/mermaid-cli` renders a small diagram instead of printing
the version.

## Upgrade

The agent image is rebuilt once under the tag `1.38.0-0.21.1` and the agent pod restarts.
A release with its own `build.tools` adds `args: --allow-scripts=<package>` to an npm tool
whose dependency needs its install script.
