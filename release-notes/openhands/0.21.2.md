# openhands 0.21.2

Released 2026-11-10.

## Changes

### The default agent works on a new install

Agent Canvas 1.38.0 creates the agent profile `default` on its first start, before the
chart writes the model, with a reference to an LLM profile `default` that it never saves.
A new conversation with that agent failed with `LLM profile 'default' not found`. At every
start the chart now points each OpenHands agent profile whose LLM profile does not exist
at the active LLM profile. A reference to an existing LLM profile is left as it is.

### Renovate uses its RE2 regular expressions again

`renovate` allows the install script of its dependency `re2`, which fetches the prebuilt
native module; without it Renovate fell back to JavaScript regular expressions. The build
check of `renovate` loads `re2`.

The install scripts that stay skipped only print notices or are optional: `core-js` and
`core-js-pure` (funding banner), `protobufjs` (version notice) and `dtrace-provider`
(optional DTrace probes).

## Upgrade

The agent image is rebuilt once under the tag `1.38.0-0.21.2` and the agent pod restarts.
