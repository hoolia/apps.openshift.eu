# openhands 0.19.0

Released 2026-11-05.

## Changes

### Chat in the editor, set up from the agent's models and MCP servers

The editor (**VS Code** in the UI) ships the Continue extension. A new container,
`vscode-sync`, writes its configuration every minute: every model of the gateway,
through the token proxy, and every enabled MCP server of the agent. The default chat
model is the first gateway model named in `vscode.chat.preferredModels`
(`glm-5.3-flash`, then `qwen3-coder-next`), or the first of `vscode.chat.models`.
The built-in VS Code chat, which needs a GitHub Copilot sign-in, is switched off.

## Upgrade

The image is built again (new tag) and the pod restarts once with the new container.
A Continue configuration the user wrote by hand is kept when its first line is
removed.
