# openhands 0.21.4

Released 2026-11-10.

## Changes

### The image build no longer fails on the Azure CLI check

The check of `az` started a background telemetry upload that could still write into
`/tmp/.azure` when the check script removed it, and the build failed with
`rm: cannot remove '/tmp/.azure': Directory not empty`. The checks run with Azure CLI
telemetry off, and the cleanup after them no longer fails the build.

## Upgrade

The agent image is rebuilt once under the tag `1.38.0-0.21.4` and the agent pod restarts.
