# openhands 0.21.3

Released 2026-11-10.

## Changes

### MCP tools answer again

Agent Canvas 1.38.0 hands the `timeout` of an MCP server to fastmcp 4, which reads it in
milliseconds; the chart wrote seconds. Every MCP server of the chart therefore had 60 ms:
a tool call of a RemoteMCPServer failed with a read timeout and the `kubernetes` server
did not start (`Request 'initialize' timed out`). The chart now writes 60000 for the
RemoteMCPServers, the `kubernetes` server and the servers of `mcpServers`, whose
`timeout` value stays in seconds. Running pods take the new value from `mcp-sync` within
`mcp.interval` and from the seed at the next start.

## Upgrade

The agent image is rebuilt once under the tag `1.38.0-0.21.3` and the agent pod restarts.
