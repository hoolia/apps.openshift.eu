# openhands 0.9.4

Released 2026-10-25.

## Changes

### MCP servers of other namespaces, as RBAC allows

MCP discovery also reads the tenant's index (mcpDiscovery.index, ConfigMap
mcp-servers in the tenant's home namespace) and adds the RemoteMCPServers of
other namespaces it names, reading each with the agent's own ServiceAccount.
A server the ServiceAccount may not read is skipped, so Kubernetes RBAC on the
RemoteMCPServer decides which servers an agent sees. A name that also exists in
the own namespace becomes <namespace>-<name>. Without the ConfigMap only the
own namespace is discovered, as before.
