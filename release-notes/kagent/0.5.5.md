## Changes

### Upstream kagent 0.10.6

The controller and UI run upstream kagent 0.10.6, the last 0.10 release: fixes for CVEs in
the runtime images, Python ADK images on Wolfi. Agent Substrate stays off; enabling it
fails the install.
