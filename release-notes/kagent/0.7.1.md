# kagent 0.7.1

Released 2026-11-21.

## Changes

### MCP tool call timeout

A `remoteMCPServers` entry without `timeout`, and the example tools server, get 300s
instead of 30s: one tool call may run as long as the platform gateway and the other MCP
clients allow.

## Upgrade

Nothing to do. An entry that sets `timeout` itself keeps its value.
