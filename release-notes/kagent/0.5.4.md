# kagent 0.5.4

Released 2026-11-07.

## Changes

### Login cookie key from a secret store

With `login.provider: openshift` and `secrets.type: externalSecret`, the value
`secrets.externalSecret.items.cookieSecret` names the store item whose `login.password`
holds the login cookie key. An ExternalSecret then writes the Secret
`<name>-login-cookie-secret` in place of the Secret the chart generates. The key must be
16, 24 or 32 characters long.

## Upgrade

Nothing to do. Without `items.cookieSecret` the chart keeps its generated key.
