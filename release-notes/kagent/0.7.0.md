# kagent 0.7.0

Released 2026-11-21.

## Changes

### Same-tenant A2A callers

New value `a2a.callerNamespaceSelector`, a LabelSelector. When set, NetworkPolicy
`<name>-a2a` of every published agent also admits port 8080 from the namespaces it
selects, so the tenant's own agents call the agent directly instead of through the
gateway; for them the NetworkPolicy alone decides, not the gateway's caller check. The
tenant is the trust domain: select its namespaces by a label tenants cannot set
themselves. Namespaces outside the selector stay denied. The schema refuses a selector
without any label or expression, because that would select every namespace.

## Upgrade

Nothing to do. With `a2a.callerNamespaceSelector` empty (the default) values that rendered
with 0.6.1 render the same.
