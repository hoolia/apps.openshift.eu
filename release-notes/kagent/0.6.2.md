# kagent 0.6.2

Released 2026-11-21.

## Changes

### Same-tenant A2A callers

New value `a2a.callerNamespaceSelector`. When set, NetworkPolicy `<name>-a2a` of every
published agent also admits port 8080 from the namespaces it selects, so the tenant's own
agents call the agent directly instead of through the gateway. The tenant is the trust
domain: select its namespaces by a label tenants cannot set themselves. Namespaces outside
the selector stay denied.

## Upgrade

Nothing to do. With `a2a.callerNamespaceSelector` empty (the default) values that rendered
with 0.6.1 render the same.
