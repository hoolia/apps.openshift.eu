# opencode-agent 0.9.0

Released 2026-11-15.

## Changes

### A plugin can get its configuration file from the chart

The new value `opencode.homeFiles` names files under `HOME` (`/workspace`) and their
content. The agent writes them on every start, before OpenCode starts, so a plugin that
reads its settings from a file in the home directory (oh-my-openagent reads
`~/.omo/omo.jsonc`) is configured from the chart's values. A string is written as it is,
any other value as JSON. A change made in the pod to such a file is lost on the next start.

## Upgrade

Nothing to do. Without `opencode.homeFiles` nothing changes; the agent pod restarts once,
because the start script in its ConfigMap changes.
