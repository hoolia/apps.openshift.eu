# opencode-agent 0.8.2

Released 2026-11-12.

## Changes

### The UI logs in again after the login expired

OpenCode 2.x registers a service worker that serves its cached page for every
navigation, also for oauth-proxy's `/oauth/start` and `/oauth/callback`. Once
the login expired, every API call got oauth-proxy's redirect to the cluster
login, which the browser reports as a network error: the UI showed its server
as offline with no providers, models or MCP servers, and a reload never
reached the login page.

The UI proxy now answers `/sw.js` itself, without a login, with a worker that
deletes the old worker's caches, unregisters and reloads the page once. Pages
are then loaded from the server again and an expired login goes through the
cluster login as before.

## Upgrade

Nothing to do. The agent pod restarts once, because the oauth-proxy arguments
and the UI proxy code change. A browser stuck on "offline" recovers on its next
page load.
