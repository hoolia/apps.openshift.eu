# opencode-agent 0.10.1

Released 2026-11-20.

## Changes

### A team login without the owner-only check

New `oauth.ownerOnly`, default `true`. With `false`, every member of `oauth.allowedGroups` logs in to the UI, and the owner keeps the login as a user of the login binding. With `true`, only the owner logs in, as before.

Nothing to do: the default renders as 0.10.0.
