# opencode-agent 0.10.0

Released 2026-11-19.

## Changes

### Public MCP servers are opt-in checkboxes

New `mcp.options` and `mcp.catalog`: each ticked name adds the public server `<name>` at `/mcp/public/<server>` through the token proxy. `mcp.servers` is unchanged, and an entry there of the same name wins. Nothing ticked means no public servers. A name in `mcp.options` that is not in `mcp.catalog` fails the render.

## Upgrade

Nothing to do: existing `mcp.servers` entries keep working.
