# opencode-agent 0.12.0

Released 2026-11-22.

## Changes

### The agent's role in its namespace is a value

`serviceAccount.clusterRole` names the ClusterRole that is bound to the agent in its own
namespace. The default stays `edit`. The standard `view` role reads the namespace without
Secrets, exec or pod creation. Operators can aggregate write rights into `view`, and a cluster
can grant rights to every authenticated account, so check both on your cluster. With an empty
value the chart creates no binding.

## Upgrade

Nothing to do. An agent set to another role loses what `edit` allowed: its shell and its
Kubernetes MCP server can then do only what the new role allows.
