# mcp-server 0.4.0

Released 2026-11-08.

## Changes

### Agent registration

New values `remoteMCPServer.*`: a kagent `RemoteMCPServer` for the server, at
`https://<route.host><path>` or `remoteMCPServer.url`. `remoteMCPServer.auth: oauth2`
sets `openhands.dev/auth: oauth2` for a server with its own OAuth broker. Without
`image.repository` the chart renders only this object, which registers a hosted MCP
server such as `https://mcp.atlassian.com/v1/mcp`.

### Credential from a secret store

New values `externalSecret.*`: an `ExternalSecret` that writes the Secret named by
`envFromSecret`, one entry per variable.

## Upgrade

Defaults are unchanged: neither object renders unless enabled.
