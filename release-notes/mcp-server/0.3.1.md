# mcp-server 0.3.1

Released 2026-11-07.

## Changes

### State that survives a restart

New values `persistence.*`: a claim `<release>-data` mounted at `/data`, kept on
uninstall, and strategy Recreate. A server that stores its users' OAuth logins keeps
them across pod restarts.

### Image tag with a digest

`image.tag` may carry a digest (`0.2.0@sha256:...`); the version label takes the part
before `@`.

## Upgrade

Defaults are unchanged: no volume unless `persistence.enabled`.
