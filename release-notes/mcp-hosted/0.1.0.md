# mcp-hosted 0.1.0

Released 2026-11-12.

## Changes

### A vendor-hosted MCP server with a team API key

The chart writes an `AgentgatewayBackend` for one hosted MCP endpoint and a
Secret or ExternalSecret with the team's API key. The gateway adds the key as a
header (`auth.header`, `auth.prefix`) or a query parameter
(`auth.queryParameter`); agents never see it. Nothing is rendered until
`endpoint.host` and a key source are set.
