# airbyte 0.3.2

Released 2026-11-10.

## Changes

### Connector versions name the connector kind

ClickHouse is both a source and a destination, and `ClickHouse: 2.1.34` set the source,
which has no such version; Airbyte then never answered and the configuration job hung.
Write `destination/ClickHouse: 2.1.34`. A plain name is used only when it names one
connector.
