# airbyte 0.2.1

Released 2026-11-10.

## Changes

### The database keeps running when Argo CD syncs

Argo CD replaced the database StatefulSet, its Service and its ExternalSecret before every
sync, which restarted PostgreSQL and left Temporal without a database connection until it
was restarted. Argo CD now applies them in place. `helm upgrade` still replaces them.
