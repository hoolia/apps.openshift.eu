# airbyte 0.2.2

Released 2026-11-10.

## Changes

### A missing connector credential no longer marks the application Degraded

The ExternalSecrets of `connections.externalSecrets` carry
`argocd.argoproj.io/ignore-healthcheck`: a connector whose vault item does not exist yet
is left out by the configuration job, and Argo CD no longer holds back the sync and the
configuration job because of it.
