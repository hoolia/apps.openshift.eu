# airbyte 0.1.0

Released 2026-11-10.

## Changes

### Add chart airbyte

Airbyte 2.5.0 in one namespace under `restricted-v2`, with a Route for the web UI and the
API, MinIO for logs and state, and an MCP server that lets AI agents list connections,
start syncs and read job status.

Sources, destinations and connections can be declared in values; a Job applies them
through the Airbyte API after every install and upgrade and skips any whose credential
Secret does not exist yet.
