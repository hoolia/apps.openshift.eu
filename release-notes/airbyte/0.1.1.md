# airbyte 0.1.1

Released 2026-11-10.

## Changes

### Credential Secrets are found from the placeholders

The configuration job mounts every Secret that a `${secret:<Secret>/<key>}` placeholder
names; a source no longer needs a separate Secret name. `${secretlist:<Secret>/<key>}`
reads a comma-separated value as a list, for connector fields such as Facebook's
`account_ids`.
