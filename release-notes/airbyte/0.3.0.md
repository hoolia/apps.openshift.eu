# airbyte 0.3.0

Released 2026-11-10.

## Changes

### Argo CD orders the database by sync waves, not hooks

With `installMode: argocd` (the default) the database, its Service and Secret and the
bootloader account are normal objects in early sync waves, and the bootloader runs as a
Sync hook after them. Argo CD no longer deletes or replaces the database: a failed sync
removed the hook database of 0.2.1 and 0.2.2. The data stays on the volume claim
`airbyte-volume-db-airbyte-db-0`.

`helm install` needs `installMode: helm` (install hooks, as before) and
`upstream.airbyteBootloader.annotations: {}`.
