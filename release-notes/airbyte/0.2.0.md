# airbyte 0.2.0

Released 2026-11-10.

## Changes

### The database password comes from a Secret

The chart runs its own PostgreSQL (`database.enabled`) instead of upstream's bundled one,
with the password from Secret `airbyte-db-credentials`: from the vault item
`secrets.externalSecret.items.database`, or created once in the cluster by an install hook.
The values no longer carry a database password; `upstream.postgresql.postgresqlPassword`
and `global.database.password` are gone.

Upgrading from 0.1: the database keeps its volume claim `airbyte-volume-db-airbyte-db-0`
and its data. It keeps the password it was created with, so put that password in the
vault item before the upgrade (user `airbyte`).

### Connector credentials from a secret store

`connections.externalSecrets` creates the Secrets that `${secret:...}` placeholders read,
from vault items, so a tenant needs no objects outside the chart.

### Connector versions are values

`connections.definitionVersions` sets a connector's image tag, for example
`ClickHouse: 2.1.34`, which ClickHouse 26.8 and later need.
