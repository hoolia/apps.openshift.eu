# accountant-agent 0.1.0

Released 2026-11-08.

## Changes

### A bookkeeper and a cfo agent over A2A

One Deployment serves the roles `bookkeeper` (daily) and `cfo` (weekly), each on its own
port with its own agent card, CronJob and, with kagent installed, BYO Agent
`<release>-<role>`. The agent takes its tools from the MCP servers in `mcpServers` and its
model from `model.baseUrl`, with the pod's ServiceAccount token as credential.

### Approvals as A2A input-required

A draft that needs approval stops the task in state `input-required` with a short summary
and the answers `boek <id>` and `afkeuren <id> <reason>`. The answer goes back on the same
task; the MCP server that commits the draft checks the approval.

### A ledger with a seven-year audit trail

CloudNativePG Cluster `<release>-ledger` holds the tables `ledger`, `audit` and `documents`.
Rows are kept `ledger.retentionYears` (7) years, the audit trail is append-only, and the
Secret `<release>-ledger-app` gives the MCP server that writes bookings its database URL.
