# mcp-odoo 0.1.0

Released 2026-11-13.

## Changes

### First release

Odoo as an MCP server (ivnvxd/mcp-server-odoo 0.9.0) for a tenant or one of
its teams, in catalog category crm. The server acts as one Odoo user through
its API key from an existing Secret. `odoo.yolo` decides what it offers:
`off` (default) the models of the Odoo MCP module, `read` every model
read-only, `true` read and write without the module. An optional token check
(`auth.enabled`, library chart `mcp-auth`) protects the server when no
authenticating MCP gateway stands in front of it.
