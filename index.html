Helm Charts

Applications for the GRN.CLOUD platform. Deploy one in your own project from the console, or install the chart yourself with Helm. No cluster-admin rights needed.

Deploy from the console

The Deploy button opens the managed version in console.grn.cloud: pick your project, fill in a name, and Argo CD installs and updates the application.

Install with Helm

helm repo add grncloud https://apps.openshift.eu
helm repo update
helm search repo grncloud
