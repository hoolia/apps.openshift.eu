GRN.CLOUD Apps

Helm charts for the GRN.CLOUD tenant app marketplace. Each chart installs one application in your own OpenShift project, without cluster-admin rights.

Use this repository

helm repo add grncloud https://apps.openshift.eu
helm repo update
helm search repo grncloud

Charts

The chart list is in index.yaml.

Source and documentation per chart: github.com/hoolia/apps.openshift.eu. Repository index: index.yaml.
